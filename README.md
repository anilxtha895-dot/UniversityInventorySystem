# University Inventory System

## Description
This is a Java project developed for a programming assignment.
The system is built to manage equipment, lab equipment and furniture.
It allows staff members to register, assign equipment, return equipment and generate reports.

## Features
- Add new equipment items
- Register new staff members
- Assign equipment to staff
- Return equipment
- Search inventory items
- Generate reports

## Technologies Used
- Java
- Eclipse IDE
- GitHub

## What I Learned
- Creating and using classes in Java
- Using inheritance and abstract classes
- Creating custom exceptions
- Using loops (for, while, do-while, enhanced for)
- Using ArrayList and arrays
- Building a menu-driven console program
